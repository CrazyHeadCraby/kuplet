# Куплет

Студия караоке-кадров для музыкальной викторины.
На экране идёт отрывок песни, строки сменяются как в караоке. Ролик пишется сам — OBS не нужен.
Песня и текст остаются в браузере и никуда не отправляются.

Рабочая студия открывается в превью чата Grok. Лучше всего в Chrome или Edge: там запись часто сразу в mp4.

## Как снять вопрос

1. «Новый вопрос». Или «Демо-сцена», чтобы увидеть кадр без своей песни.
2. Перетащите mp3, wav, m4a, ogg или flac.
3. Вставьте текст: одна строка — одна смена в кадре. Можно файл `.txt` или `.lrc` (время из LRC станет метками).
4. На волне выделите отрывок, где название звучит вслух. Края тянутся, середина двигает весь кусок, колесо мыши масштабирует. `I` — начало по курсору, `O` — конец.
5. Звезда на строке — пометка «здесь звучит название». В ролик она не попадает, это только подсказка вам.
6. Кликните мимо поля текста и нажимайте пробел вдоль песни — строка плавно сменяется, время запоминается.
7. «Снять ролик». Если метки уже есть, включите «По меткам» — строки сменятся сами, пробел их поправит.
8. Скачайте файл. Кадр 1920×1080, 1080×1920 или 1080×1080.

Подсказка «Дальше» на экране в ролик не входит: пишется только кадр со строкой и звук песни.

Не переключайте вкладку, пока идёт запись: кадр замрёт, а звук уйдёт вперёд.

## Клавиши

| Клавиша | Действие |
| --- | --- |
| Пробел | следующая строка |
| ← / Backspace | строка назад |
| I / O | начало и конец отрывка по курсору |
| Esc | стоп |

Проект можно скачать как JSON (без аудио) и открыть на другом компьютере, приложив песню заново.
